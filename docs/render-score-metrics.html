PRTdemo 渲染评分指标

最终 case score 观察完整显示画面的感知差异与 linear HDR 间接光能量差异；Worst-patch FLIP 与被遮挡区域中的单向漏光作为 diagnostics。四个分数均归一化到 0～1，1 表示在对应指标下与 Offline reference 完全一致。

统一输入约定：Offline 与 Realtime 均使用相同 camera、light、material、viewport 和 deterministic 2×2 SSAA。FLIP 与 Worst-patch FLIP 使用 tone-mapped display PNG；indirect transport 与 occlusion leak 使用未 tone mapping 的 indirect linear HDR PFM。error 图仅用于解释，不参与分数计算。

1. perceptualFlip：人眼感知的整图差异

FLIP 根据颜色、亮度、局部结构和观察条件估计人眼可见差异。项目使用 67 pixels/degree。每个像素的 FLIP error 位于 0～1，再对整张图取 mean。

perceptualFlip = 1 − mean(FLIP(Offline display, Realtime display, ppd=67))

它最接近“整体看起来像不像”。NVIDIA 建议必须压成单值时使用 mean，但局部严重 artifact 仍可能被大量正确 pixels 稀释，因此另外保留 Worst-patch FLIP diagnostic。

1b. worstPatchFlip：局部严重感知误差（diagnosticOnly）

把完整 FLIP error map 划分为 32×32 pixel tiles，计算每个 tile 的 mean error，再取所有 tile means 的 p95。它强调成片的 shadow acne、moiré 和局部 aliasing，同时避免单 pixel max 对孤立噪点过度敏感。

Eworst = p95({ mean(FLIP error in each 32×32 tile) })
worstPatchFlip = 1 − Eworst

该值不进入 case total，但其 per-case improvement median 是正式 A/B regression gate 之一。它与 perceptualFlip 共用 error-perceptual-flip.png，无需第二次视觉误差计算。

2. indirectTransport：间接光能量是否一致

对 Offline indirect R 与 Realtime indirect C 的 linear RGB 全部通道计算 symmetric L1。分母使用双方能量之和，因此 Offline 偏亮和 Realtime 偏亮都会受到同等惩罚，并且整体 light intensity 线性缩放时分数基本不变。

Etransport = Σ|C − R| / Σ(C + R)
indirectTransport = 1 − Etransport

这个指标直接检查 GI transport，而不会被 direct light、白色 light sphere 或 tone mapping 掩盖。两张图都全黑时定义为 1。

3. occlusionLeak：被遮挡区域是否出现过量间接光（diagnosticOnly）

Offline renderer 根据 2×2 SSAA 的四个 subpixel 生成 occlusion coverage mask M，权重为 0、¼、½、¾ 或 1。只在 mask 内比较 indirect luminance，并且只惩罚 C > R 的过量能量；Realtime 更暗不属于 light leaking，由 indirectTransport 负责评价。

Eleak = Σ M·max(C − R, 0) / Σ M·max(C, R)
occlusionLeak = 1 − Eleak

mask 为空表示该 camera/light 几何没有可观测的被遮挡 subpixel，此时分数定义为 1。该指标采用单向 excess error，可能奖励过暗结果，因此只用于定位问题，不参与 Strict score 或 Normalized improvement。

跨 case Regression gates

Candidate 先按所有 strict cases 计算原有 mean improvement；随后检查两个无阈值 majority gates。只有三项条件全部成立，ungated normalized improvement 才成为正式分数：

mean(totalB − totalA) > 0
median(perceptualFlipB − perceptualFlipA) > 0
median(worstPatchFlipB − worstPatchFlipA) > 0

任一 median 不为正，说明至少一半 cases 没有在该感知维度上改善，decision 记为 failed-regression，正式 normalizedImprovementScore=0；原平均收益仍保存为 ungatedNormalizedImprovementScore，用于分析“少数大幅改善抵消多数退化”的情况。

为什么 case-0037 / case-0038 的 Leak 只有 0.386864

两条 case 的 camera/light position 相同，仅 light intensity 分别为 150 和 250。mask 只有 836 pixels，集中在屏幕左右两侧立方体与地面的狭窄遮挡带；这些 pixels 中 Realtime indirect 全部比 Offline reference 更亮。Offline masked luminance 约为 Realtime 的 38.686%，所以：

occlusionLeak = 1 − (Realtime − Offline) / Realtime = Offline / Realtime ≈ 0.386864

不同 light intensity 得到相同分数，说明误差随能量线性缩放，是稀疏 Probe interpolation 与低阶 SH 无法表达尖锐 visibility discontinuity 的系统性误差，而不是 4096 SPP reference noise。
